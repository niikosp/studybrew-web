# studybrew-web
A website made for Studybrew.

StudyBrew is an innovative app combining education, communication and AI features. It connects students by organizing study groups at nearby cafes and study-friendly locations based on their availability. An integrated AI assistant matches users sharing common subjects and interests, answers academic questions and creates personalized study plans.
